# Design the 3D portfolio

Start with what a visitor should understand about the owner and what they should be able to do. Gather a few personal references from the owner. For each reference, identify the quality worth borrowing, such as framing, material, light, pacing, or sound. Use those qualities to make a direction that belongs to this portfolio.

## Compare directions

1. Describe the visit with verbs. Pick one representative path, such as finding a project, opening it, and returning to the gallery.
2. Sketch distinct ways to stage that path with the same real project content. Compare the opening frame, the first action a visitor can discover, and how the project becomes readable. Show a narrow viewport beside the desktop view.
3. Use a still or storyboard for a question about composition. Use a clickable blockout when the question is whether a visitor understands the interaction. Test the riskiest technical assumption with the tool that can answer it, such as a Blender render for soft bounce light or a browser prototype for touch navigation.
4. Collect reactions to the actual previews. Make targeted variations of the strongest direction, changing one consequential choice at a time. Record the approved direction, the interaction it depends on, and the evidence still needed.

Keep the first prototype centered on one idea. Give the visitor one satisfying interaction before extending the scene or adding media. Use the same project content to sketch the HTML view so the portfolio works as a reading experience as well.
