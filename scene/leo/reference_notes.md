# 雷歐建模參考

下列編號對應原始調查素材的照片和影片。公開選圖及其灰階深度圖收錄在雷歐書頁的[建模參考](../../content/books/leo/02-model-references.md)。

| 素材 | 可辨認的特徵 | 建模決定 |
| --- | --- | --- |
| 0194、0313、0655 | 窄而高的耳朵、略寬的頰部、橄欖金色虹膜、磚粉鼻、白下巴 | 正面以 0194 核對耳距與眼距，兩張斜面核對鼻口突出量與耳殼厚度 |
| 0532、0791、0262-01100 | 圓潤軀幹、略下垂的後腹、後腿折角、尾巴細而有環紋 | 用前後腳的落點和背線推定站姿，避免沿用低頭吃飯的頸部角度 |
| 0620、0947、0016-04287 | 背中線、腰臀體積、尾根方向 | 用俯視和背面檢查軀幹厚度、尾根與尾尖的彎曲 |
| 0315、0759、0583 | 淡色下巴與腹部、橘色腳趾與粉褐肉墊 | 腹側和趾墊均建入，照片的光源差異以溫暖的中間色處理 |

照片中的貓姿勢和拍攝距離不同。深度圖逐張比對頭、胸和臀部的前後順序，以及腿與尾巴遮擋。深度值為相對估計，四肢末端貼地時常與背景合併。暫以肩高約 30 cm 的自然站姿作為模型基準，肢體背面的輪廓和部分毛紋由可見角度推定。

## 補找的站姿影格

| 影片時間碼 | 形體觀察 | 採用方式 |
| --- | --- | --- |
| 0262，00:01.57 | 走路時頭頸低於初版，臀部至肩部的背線接近平緩，尾巴從臀部向上收 | 降低頭頸、減少前胸突出、縮短尾巴向後伸出的距離 |
| 0272，00:21.90 | 低角度看得到尾根、臀寬和後腳踝折角 | 確認臀部與尾根的連續面，保留後腿從粗到細的過渡 |
| 0289，00:08.00 | 兩隻後腳都有入鏡，尾根與臀部可辨認 | 核對後腳站距、後腹和臀部的寬度 |
| 0352，00:21.67 | 短暫站定時可同時看到胸、肩和軀幹厚度 | 交叉核對走路影格，避免把單一步態的落腳當成站姿 |

輪廓比較以相近視角和同一組相機參數觀察修正前後。相簿仍缺同一姿勢、同一高度的四視圖，步態、頭部轉向和拍攝透視會造成差異。

## 身形修整

軀幹改用連續的截面控制背線、腹線和寬度。0262 的側面影格用來核對臀部至肩胛的連續背線與後腹收束，0352 的站姿用來核對胸腹厚度和前腿從肘到腕的輪廓。0289 與 0272 的後方影格用來核對尾根、臀寬和後腳站距。腳掌的輪廓與肉墊共用落腳中心。

三個角度的身形目視自評為 8.5 / 10。主要落差仍在轉頭、落腳和尾尖位置。頭臉細節與毛色未納入身形評分。

## Blender 檔案

`public/models/leo.blend` 是站姿雕塑，主體、尾巴和耳朵為連續網格。選取主體後，在 **Material Properties → Coat · change color here → Base Color** 修改主色。虹膜、鼻頭、鬍鬚和肉墊各自有純色材質。場景的 `Leo` 集合可供 Append。此版的網格密度以雕塑編輯與輪廓檢查為目的，尚未做動畫用拓撲和骨架。

在專案根目錄用 Blender 5.2 重新產生檔案。

```sh
blender --background --factory-startup --python-exit-code 1 --python scene/leo/build.py
```

網頁預覽使用同一個雕塑的簡化網格。修改 Blender 檔後，可在專案根目錄重新匯出。

```sh
blender --background public/models/leo.blend --python-exit-code 1 --python scene/leo/export_web.py -- --output public/models/leo.glbz
```
