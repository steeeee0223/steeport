# Steeport 建置里程碑

訪客從咖啡廳的窗邊座位開始。起身後可以到隔壁蓋閱讀室，或沿人行道走到駭客工作室。

- **寫實視角。** 以訪客的眼睛高度看店內和窗外。
- **像素視角。** 從斜上方看店內，可旋轉鏡頭。畫面要看得到角色、窗框、吧台正面和桌椅間的通道。

兩種視角共用場景、碰撞範圍和物件狀態。

## 目前進度

首頁 `/` 目前可以切換視角、操作咖啡廳的物件、建造閱讀室和造訪工作室。工作室的電子門鎖、旋轉椅和維修桌下的保險櫃都能操作。練習終端機也能從靜態首頁開啟。[操作方式](scene-interaction.md)

《Steeport 開發日誌》、《雷歐》和 **Trail journal** 都能在店內或 `/books/` 閱讀。接下來要用實體手機量測效能，確認 M5 的作品清單，再請第一次造訪的人試用。[M4 效能紀錄](m4-review.md)

## 建模前的起點

- 平面圖標出中央的六人長桌、左側的三組小桌、右側的吧台和後牆的書架。飲水區在吧台尾端。尺寸在第一次建模時確認。[室內平面圖](cafe-floor-plan.svg)
- 寫實版先試午後光從開窗照進來的效果，以及坐在窗邊和起身回頭時的構圖。像素版參考兩張遊戲畫面，從斜上方保留牆面、桌腳和角色的高度感。
- 先在簡模試第一人稱走動，再用正式模型測兩種視角和物件操作。兩次使用相同的房間比例。

Steeport 參考 Felix Rieseberg 的做法，先用 Blender 試構圖，再用桌機和手機操作預覽。比較窗景時，固定截圖角度並量測效能。[Felix Rieseberg 的建置紀錄](https://felixrieseberg.com/made-by-mechanical-means/)

## M1　用同一張平面圖搭出兩種視角

**交付。** 定好兩種視角共用的房間尺寸、家具位置、碰撞範圍和操作站位。用 Blender 簡模渲染窗邊坐姿和起身回頭兩張圖。用同一個簡模試像素版的斜角鏡頭，從幾個方向看角色和家具，確認掛畫與書架朝向店內。

**完成條件。** 兩版的窗、桌椅、長吧台和書架都落在同一格局。寫實版坐著看得到窗外和桌上物件，起身後看得出室內配置。像素版要同時看得到桌面、桌腳和吧台正面。角色經過長桌前後時，仍能辨認所在位置和可走的通道。用桌機和手機窄幅預覽確認兩版都找得到窗邊。

## M2　做出可以走動和一鍵切換的原型

**交付。** 在瀏覽器預覽中用一個按鈕切換寫實和像素視角。加入走動、轉向、坐下、起身和筆電開合。像素視角可旋轉鏡頭。

**完成條件。** 桌機可用鍵盤走動，手機可用觸控移動。旋轉像素鏡頭或切換視角時，角色留在原位並維持原來的面向。掀開筆電後切換視角，筆電仍開著。兩種視角都能從同一側繞過桌椅。切換中斷或快速連點後仍可操作。

## M3　完成咖啡廳內的物件操作

**交付。** 逐項加入翻書、從書架取書、在吧台裝水、接上筆電充電線，以及和店貓互動。每完成一個動作，就在兩種視角各走一次。筆電和書先使用測試內容。

**完成條件。** 兩種視角都能辨認可操作的物件並完成相同的動作。切換視角時，手上物件、杯中水量、充電線和店貓的位置都保留。

## M4　定稿畫面並量測效能

**交付。** 完成材質、午後光、街景、像素畫面與動畫。用坐姿、站姿和沿窗移動的畫面比較兩種窗景，一種全用 3D 模型，另一種用深度圖重建遠處建築。量測首次載入、走動時的幀時間和切換時間，再決定要烘焙哪些光影，以及何時載入場景資產。

**完成條件。** 寫實窗景在三種視角都有合理的遮擋和視差。像素版在手機上能看清角色、通道與可操作的物件。在一台指定手機和一台桌機驗證兩版的載入、操作和往返切換。記下裝置、量測目標與結果，方便用同樣步驟重測。

桌機 Chrome 與手機模擬的結果、窗景選擇和重測步驟記在 [M4 驗證紀錄](m4-review.md)。

## M5　放入真實作品

開發日誌、雷歐的建模資料和短篇旅行手帳已發布。原定的作品清單如下。

**交付。** 筆電至少有一個真實 GitHub 專案，代數幾何筆記至少有一篇章節，旅行手帳至少有一趟行程。每份內容有獨立的 HTML 閱讀頁和可分享連結，兩種視角都能從對應物件開啟。

**完成條件。** 三種內容在手機上都能讀，公式和行程順序清楚。讀完後能回到店內原位。場景載入失敗時，仍可透過作品連結閱讀。

## M6　驗收並準備上線

Playwright 已測試切換視角、鍵盤和模擬觸控、建造模式、工作室與靜態首頁。這一階段還需要用實體裝置測試，並請第一次造訪的人試用。

**交付。** 可分享的預覽，包含兩種視角、店內操作和 HTML 作品頁。檢查作品連結、手機版、鍵盤、減少動態效果設定，以及場景載入失敗時的瀏覽方式。

**完成條件。** 請至少一位第一次看到網站的人自行找到切換方式、完成一次店內操作，再開啟一件作品並回到咖啡廳。記下卡住的地方，修正影響切換、移動和閱讀的問題，再確認公開版本。
