# Steeport 建置里程碑

Steeport 是一間可以走動的午後咖啡廳。訪客從開窗旁的座位開始，可以起身逛店、操作物件，再回到窗邊。場景有兩種呈現方式，可以一鍵切換。

- **寫實視角。** 從訪客眼睛的高度看咖啡廳。坐著可以看窗外，站起來可以轉頭和走動。
- **像素視角。** 採用第三人稱斜角鏡頭，從房間斜前方看進店內。訪客可以在遊玩時旋轉鏡頭。畫面要看得到角色的身體、窗框和吧台的立面，以及桌椅之間的通道。

兩種視角共用同一個 3D 咖啡廳、碰撞範圍和互動狀態。場景和操作驗證後，再放入作品內容。[視角與操作需求](scene-interaction.md)

## 目前的起點

- 室內格局已暫定。右側是長吧台，尾端設自助飲水區。中央是六人公共長桌，左側有三組靠牆小桌。後牆有書架、掛畫和植物。平面圖記錄相對位置，尺寸由第一次建模驗證。[室內平面圖](cafe-floor-plan.svg)
- 開放窗、午後自然光、窗邊坐姿和起身回頭的構圖已有方向。像素版沿用同一個空間配置，參考使用者提供的兩張遊戲畫面，保留牆面、桌腳和角色的高度感。
- 簡化場景已試過第一人稱走動。正式的房間比例、兩種視角的切換和物件互動從以下里程碑開始驗證。

Felix Rieseberg 從多個概念預覽選出方向，用 Blender 試渲染來改場景，再透過桌機和手機的可操作預覽反覆調整。他也比較過多種窗景做法，並用同角度截圖搭配效能量測來檢查優化。Steeport 每一輪先看交付物，再決定哪個問題值得進下一輪。[Felix 的建置紀錄](https://felixrieseberg.com/made-by-mechanical-means/)

## M1　用同一張平面圖搭出兩種視角

**交付。** 建立共用的房間尺寸、家具位置、碰撞範圍和互動站位。用 Blender 搭寫實場景的簡模，輸出窗邊坐姿和起身回頭兩張試渲染。用同一個 3D 場景試像素版的斜角鏡頭，從數個方向看角色、窗邊木桌和主要家具，確認掛畫與書架都朝向店內。

**完成條件。** 兩版的窗、桌椅、長吧台和書架都落在同一格局。寫實版坐著看得到窗外和桌上物件，起身後看得出室內配置。像素版要同時看得到桌面、桌腳和吧台正面。角色經過長桌前後時，仍能辨認所在位置和可走的通道。用桌機和手機窄幅預覽確認兩版都找得到窗邊。

## M2　做出可以走動和一鍵切換的原型

**交付。** 在同一個瀏覽器預覽中接上寫實與像素視角，用一個控制切換。先完成走動、轉向、坐下、起身、回窗邊和掀開筆電。加入像素版的鏡頭旋轉。用測試畫面確認筆電可以開合和保留狀態。

**完成條件。** 桌機可以用鍵盤走動，手機可以用觸控移動。像素版旋轉鏡頭時，角色位置和面向維持原狀。從窗邊走到吧台再切換，角色出現在吧台同一位置，面向也保留。回到窗邊，掀開筆電後來回切換，筆電仍維持開啟。兩種視角都能從同一側繞過桌椅，切換中斷或快速連點後仍能繼續操作。

## M3　完成咖啡廳內的物件操作

**交付。** 逐項加入翻書、從書架取書、在吧台裝水、接上筆電充電線，以及和店貓互動。每完成一個動作，就在兩種視角各走一次。筆電和書先使用測試內容。

**完成條件。** 兩種視角都能辨認可操作的物件並完成同一動作。拿著書或裝好水時切換，手上物件和杯中水量都保留。已接上的充電線和店貓的位置也會在切換後對得上。

## M4　定稿畫面並量測效能

**交付。** 做出寫實版的材質、午後光和街景，以及同一個 3D 場景的像素風格、角色和物件動畫。寫實窗景比較完整 3D 簡模和近景幾何搭配遠景深度圖，用坐姿、站姿和沿窗移動的畫面對照。先量首次載入、走動時的幀時間和切換等待，再決定固定光影如何烘焙、兩種視角的資產何時載入。

**完成條件。** 寫實窗景在三種視角都有合理的遮擋和視差。像素版在手機上能看清角色、通道與可操作的物件。在一台指定手機和一台桌機驗證兩版的載入、操作和往返切換。記下裝置、量測目標與結果，方便用同樣步驟重測。

## M5　放入真實作品

**交付。** 筆電至少有一個真實 GitHub 專案，代數幾何筆記至少有一篇章節，旅行手帳至少有一趟行程。每份內容有獨立的 HTML 閱讀頁和可分享連結，兩種視角都能從對應物件開啟。

**完成條件。** 三種內容在手機上都能讀，公式和行程順序清楚。讀完後能回到原本的位置。遇到場景載入失敗或直接開啟作品連結時，仍可讀取同一份內容。

## M6　驗收並準備上線

**交付。** 可分享的預覽，包含雙視角場景、店內操作和一般 HTML 瀏覽方式。確認作品連結、行動版、鍵盤、減少動態效果偏好，以及場景載入失敗時的回退方式。

**完成條件。** 請至少一位第一次看到網站的人自行找到切換方式、完成一次店內操作，再開啟一件作品並回到咖啡廳。記下卡住的地方，修正影響切換、移動和閱讀的問題，再確認公開版本。
