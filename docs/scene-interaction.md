# 咖啡廳視角與操作需求

## 同一間 3D 咖啡廳

寫實第一人稱和像素第三人稱共用同一個 3D 場景。兩種風格的牆、窗、家具和擺設沿用同一份模型、位置、尺寸、朝向與碰撞範圍。風格切換時，換的是鏡頭和畫面的呈現方式。家具以暫定平面圖為準，掛畫和書架都朝向店內。[室內平面圖](cafe-floor-plan.svg)

## 鏡頭

- **寫實第一人稱。** 從訪客眼睛的高度看。坐著可以轉頭看窗外和桌上物件，站起來可以走動。
- **像素第三人稱。** 預設從房間斜前方看進去，能看到角色、桌腳、窗框和吧台正面。訪客在遊玩時可以旋轉鏡頭，從其他方向看同一間店。轉動鏡頭時，角色留在原位，面向也維持原本的方向。
- 旋轉後如果牆面遮住角色或互動物件，試在畫面上切低或隱藏擋住視線的牆。牆的碰撞和家具朝向由共用場景決定。預設角度、旋轉範圍和操作手勢留到原型試用後再定。

## 走動、互動與切換

- 兩種風格都能走動、轉向、坐下、起身和回窗邊。桌機支援鍵盤移動，手機支援觸控移動。像素版的轉鏡頭和移動是分開的操作。
- 兩種風格都能掀開筆電、翻書、從書架取書、在吧台裝水、接上筆電充電線，以及和店貓互動。每個物件在兩種風格使用同一套操作規則。
- 以一個控制切換風格。切換前後保留角色位置、面向、坐姿或站姿、手上物件和店內狀態。例如，坐著掀開筆電後切換，角色仍在原座位，筆電仍開著。

## 原型怎麼驗收

1. 在像素版走到長桌旁，停下並旋轉鏡頭。確認角色腳下的位置和角色面向都維持原狀，仍能辨認通道和下一個要操作的物件。
2. 走到書架，在兩種風格間切換。確認角色站在同一個位置，書架與掛畫的正面都朝店內。
3. 回到窗邊坐下並掀開筆電，再來回切換。確認坐姿、座位和筆電狀態接續。等取書和裝水做完，再用手上拿著物件的情況重測。
4. 用桌機與手機各試一次移動、轉鏡頭和切換，確認操作互不干擾。
