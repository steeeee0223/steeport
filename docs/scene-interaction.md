# 咖啡廳視角與操作

## 同一間 3D 咖啡廳

寫實第一人稱和像素第三人稱共用同一個 3D 場景。兩種風格的牆、窗、家具和擺設沿用同一份模型、位置、尺寸、朝向與碰撞範圍。現行尺寸與家具位置記在 [場景配置](../scene/layout.json)，最初的構想記在 [室內平面圖](cafe-floor-plan.svg)。

## 鏡頭

- **寫實第一人稱。** 從訪客眼睛的高度看。坐著可以轉頭看窗外和桌上物件，站起來可以走動。
- **像素第三人稱。** 預設用等角正交鏡頭俯看房間。可旋轉鏡頭或用 **+** 拉近。轉動鏡頭時，角色留在原位，面向也維持原本的方向。鏡頭會依角度隱藏部分牆面，碰撞範圍沿用共用場景。

## 走動、互動與切換

- 兩種風格共用鍵盤操作。**WASD** 或方向鍵移動，**Q** 和 **E** 轉鏡頭，**C** 起身或在附近座位坐下，**X** 切換蹲姿，**F** 執行提示動作。觸控裝置起身後可按住畫面方向鍵走動，拖曳可轉鏡頭。
- 可坐在窗邊、公共桌或靠牆座位。走動時撞到活動椅，若前方有空間就會把椅子推開。
- 掀開筆電後點螢幕可拉近，按 **Esc** 回到原視角。窗邊筆電可接上充電線。桌上筆記本可以翻頁。書架上的圖冊和旅行手帳都可取閱，歸還後即可換另一本。
- 在吧台裝水後可拿著杯子喝水。要放下杯子或手上的書，選取對應的 **Put down**，再點可觸及的空桌面或檯面。也可按 **F** 嘗試放在畫面中央附近。
- 站在 Miso 附近蹲下可摸牠。可從店內開關入口的門並看到街景。訪客的移動範圍在店內。
- 以一個控制切換風格。切換前後保留角色位置、面向、坐姿或站姿、手上物件和店內狀態。例如，坐著掀開筆電後切換，角色仍在原座位，筆電仍開著。

## 手動驗收

1. 在像素版走到長桌旁，停下並旋轉鏡頭。確認角色腳下的位置和角色面向都維持原狀，仍能辨認通道和下一個要操作的物件。
2. 走到書架，在兩種風格間切換。確認角色站在同一個位置，書架與掛畫的正面都朝店內。
3. 回到窗邊坐下並掀開筆電，再來回切換。確認坐姿、座位和筆電狀態接續。點螢幕拉近，再按 **Esc** 返回。
4. 從書架取一本書，再到吧台裝水。來回切換視角，確認書和杯中水量保留，再找附近的空桌面放下兩樣物件。
5. 用桌機與手機各試一次移動、轉鏡頭和切換，確認操作互不干擾。

筆電和書本目前使用測試內容。作品內容和公開版本的交付條件記在 [建置里程碑](milestones.md)。
