# Steeport 視角與操作

進入首頁時，你坐在咖啡廳的窗邊。右上角的 **Settings** 有 **Controls**、**Pixel view** 和 **Build mode**。切換視角時，角色會留在原位，面向、姿勢和物件的位置都會保留。

## 鍵盤操作

| 按鍵 | 動作 |
| --- | --- |
| **W**、**A**、**S**、**D** 或方向鍵 | 走動。坐在工作室的旋轉椅上時，連椅子一起移動。 |
| **Shift** | 起身後按住，再按移動鍵跑步。 |
| **Space** | 起身後跳躍。看影片時可播放或暫停。 |
| **Q** 或 **E** | 向左或向右轉鏡頭。在像素視角中，角色的位置和面向不變。 |
| **C** | 起身，或在附近的座位坐下。 |
| **X** | 蹲下或站直。靠近 Leo 蹲下後，可選 **Pet Leo**。 |
| **V** | 切換第一人稱和像素視角。 |
| **Z** | 在像素視角拉近或拉遠。 |
| **F** 或畫面顯示的數字鍵 | 執行提示旁的動作。放置物件時，**F** 會嘗試放在畫面中央附近。 |
| **T** | 靠近掀開的筆電時，拉近螢幕。 |
| **R** | 閱讀手上的書。 |
| **←** 或 **→** | 閱讀時翻到上一頁或下一頁。 |
| **H** | 喝一口杯裡的水。 |
| **G** 或 **B** | 選擇放杯子或書的位置。 |
| **Esc** | 闔上書、離開螢幕特寫、取消放置物件，或退出建造模式。 |
| **M** | 播放或靜音 lo-fi 音樂。看影片時可切換影片聲音。 |

## 滑鼠與觸控

- 拖曳畫面可轉鏡頭。觸控裝置會在能移動時顯示方向鍵。按住方向鍵就能走動，坐在工作室的旋轉椅上時則會滑動椅子。
- 走近物件後，直接點它，或選工具列上的動作。要放下物件時，點伸手可及的空桌面或檯面。
- 點已掀開的筆電螢幕可拉近，點畫面外側可回到原視角。閱讀時用書上的按鈕翻頁或闔上書。
- 觸控裝置可在 **Settings** 的 **Controls** 中調整鏡頭方向、像素視角縮放和蹲姿。按鈕依當下的視角與姿勢顯示。

## 咖啡廳

- 可坐在窗邊、公共長桌或靠牆的座位。走向活動椅時，若前方有空間就能把椅子推開。
- 走到 Leo 身旁，按 **X** 蹲下，再選 **Pet Leo**。角色會用空著的手摸牠的背。雙手都拿著物件時，Leo 仍會回應。[Leo 模型開發記錄](../models/cat-archives/index.html)
- 窗邊放著《Steeport 開發日誌》，書架上放著《雷歐》和 **Trail journal**。寬螢幕顯示雙頁，窄螢幕顯示單頁。書裡的 **Open shareable page** 可分享正在讀的章節。
- 到吧台尾端裝水。窗邊的筆電可接上充電線。走近老電視後選 **Watch film**，可在特寫中播放、暫停或換片。
- 開啟系統的減少動態效果後，窗外的樹葉會停止擺動。翻頁和開關門會省略動畫。

## 建造閱讀室

1. 開啟 **Settings**，選 **Build mode**。
2. 在 **Structure** 選 **Attach room** 放入一間房，或用 **Floor** 從咖啡廳的入口開始鋪地板。拖曳可連鋪數格地板，或沿格線畫牆。
3. 從 **Furniture** 選家具。書櫃需要一排四格地板。放下家具前，看看預覽中的位置和方向會不會擋住走道。
4. 選 **Done** 或按 **Esc** 回到原視角，再走進閱讀室。自己放的門可以開關，椅子和沙發可以坐，落地燈也能開關。

用方向鍵選格，按 **R** 切換格邊，再按 **Enter** 或 **Space** 使用目前的工具。按 **,** 或 **.** 預覽家具轉向。用 **Undo** 復原上一次編輯。連續拖曳算一次編輯。

按 **Q** 或 **E** 轉鏡頭，按 **+** 或 **-** 縮放，按 **Home** 回到預設視角。選平移工具後可拖動鏡頭，觸控裝置也可用雙指縮放。

瀏覽器會儲存成功的編輯，下次開啟時可以接著蓋。

## 造訪駭客工作室

1. 起身走到咖啡廳前門，開門後沿窗外的人行道走到 **08** 號工作室。
2. 點牆上的密碼鎖或選 **Enter door code**。照面板上的值班提示，依序輸入門牌號碼和工作單號。
3. 等門朝人行道打開，再走進室內。走離門口後，門會關上並重新上鎖。要出去時，從裡面選 **Open studio door**。

- 靠近進門右側的維修桌，點桌下的保險櫃或選 **Open safe**。門沿左側鉸鏈向外打開。再選 **Close safe** 可關上。
- 在電腦桌的旋轉椅坐下後，用移動鍵在桌前前後左右滑動。按 **C** 起身。
- 選 **Use workstation** 打開練習終端機。用面板按鈕在終端機、目標電腦和事件記錄之間切換。觸控裝置也可左右滑動。瀏覽器會模擬練習資料。
- 如果 3D 場景無法載入，可在首頁的靜態畫面選 **Open hacker studio demo**，也可以從那裡開啟書籍和影片。
