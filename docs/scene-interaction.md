# 咖啡廳視角與操作

## 鍵盤操作

寫實第一人稱和像素第三人稱共用下列按鍵。切換視角時會保留角色的位置、面向、姿勢、手上物件和店內狀態。

| 按鍵                                | 動作                                                     |
| ----------------------------------- | -------------------------------------------------------- |
| **W**、**A**、**S**、**D** 或方向鍵 | 起身後走動。                                             |
| **Q** 或 **E**                      | 向左或向右轉鏡頭。在像素視角中，角色的位置和面向不變。   |
| **C**                               | 起身，或在附近的座位坐下。                               |
| **X**                               | 蹲下或站直。靠近 Leo 蹲下後，可選 **Pet Leo**。        |
| **V**                               | 切換寫實第一人稱和像素第三人稱。                         |
| **Z**                               | 在像素視角拉近或拉遠。                                   |
| **F**                               | 執行工具列的主要動作。放置物件時，嘗試放在畫面中央附近。 |
| 畫面顯示的數字鍵                    | 執行該數字旁的動作。                                     |
| **T**                               | 拉近已掀開且在操作範圍內的筆電螢幕。                     |
| **R**                               | 閱讀手上的書。                                           |
| **←** 或 **→**                      | 閱讀時翻到上一頁或下一頁。                               |
| **H**                               | 喝一口杯裡的水。                                         |
| **G**                               | 選擇放杯子的位置。                                       |
| **B**                               | 選擇放書的位置。                                         |
| **Esc**                             | 闔上書、離開筆電特寫，或取消放置物件。                   |
| **M**                               | 播放或靜音 lo-fi 音樂，閱讀時也可使用。進店時預設靜音。  |

## 滑鼠與觸控

- 拖曳畫面可轉鏡頭。在觸控裝置上，起身後按住畫面上的方向鍵走動。
- 面向並靠近物件後，可點物件或使用工具列互動。兩種視角都依角色面向判斷。選擇放置位置時，點可觸及的空桌面或檯面。
- 點已掀開的筆電螢幕可拉近。點螢幕外側可回到原視角。
- 點書上的按鈕翻頁。點關閉鈕或書本外側可闔上書。
- 右上角的齒輪可開關音效及切換像素視角。

## 店內操作

- 在像素視角中，角色會換腳轉向。放開方向鍵後，支撐腳留在原地，另一腳完成最後一步。
- 走到 Leo 身旁，按 **X** 蹲下，再選 **Pet Leo**。像素視角會顯示低蹲姿勢，角色會用空著的手摸牠的背。雙手都拿著物件時，Leo 仍會回應，角色會維持持物姿勢。[Leo 模型開發記錄](../models/cat-archives/index.html)
- 可坐在窗邊、公共長桌或靠牆的座位。走向活動椅時，若前方有空間就能把椅子推開。可從店內開關前門。
- 在窗邊選 **Read Steeport 開發日誌** 打開開發日誌。《雷歐》和旅行手帳放在書架上。寬畫面顯示雙頁，窄畫面顯示單頁。重開手上的同一本書會回到上次讀到的頁面。
- 在吧台尾端裝水。窗邊的筆電可接上充電線。
- 開啟系統的減少動態效果後，Leo 和窗外的樹葉會停在原地，書本會直接切換姿勢和頁面。
